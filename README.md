# Ideaboard

Ideaboard is an AI-powered workspace that helps turn rough ideas and thinking into **structured diagrams, visual notes, and project boards**. The goal is to provide an AI collaborator directly inside the workspace so users can move from an idea to a clear plan visually.

## Development Roadmap

We plan to build Ideaboard feature by feature:

* [ ] **1. Basic Setup** — Database and project foundation
* [ ] **2. Authentication** — User authentication and authorization
* [ ] **3. Schema & API Design** — Design the data models and APIs
* [ ] **4. Canvas** — Build the drawing and visual workspace
* [ ] **5. AI Integration** — Add the AI collaborator and AI-powered features
* [ ] **6. Test & Publish** — Testing, deployment, and production release

## Goal

Build a simple, collaborative workspace where rough thoughts can quickly become structured visual plans with the help of AI.
